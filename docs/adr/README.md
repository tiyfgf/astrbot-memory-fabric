# Architecture decision record index

- ADR-0001: AstrBot remains the host platform; Memory Fabric is a plugin.
- ADR-0002: Private-chat first, single primary user before group support.
- ADR-0003: Autonomous memory formation plus full raw ledger and post-hoc audit.
- ADR-0004: Moderate natural forgetting; preserve evidence while details fade.
- ADR-0005: Fuzzy concepts and weighted associations are first-class, not hard facts.
- ADR-0006: Proactive behavior starts with conservative B-level gates and leaves a C-level extension point.
- ADR-0007: Local Git is the source of truth; Gitee is the primary remote and GitHub is a mirror/release remote when reachable.
